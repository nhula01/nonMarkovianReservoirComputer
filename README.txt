Non-Markovian Reservoir Computing Simulation
=============

Description
-----------
We model the evolution of a non-Markovian quantum system under a driving force. In this project, we analyze the non-Markovian quantum reservoir on three different real world applications: stock market prediction, speech recognition, cancer prediction.

Requirements
------------
Python packages needed:
- numpy
- pandas
- scipy
- scikit-sklearn
- matplotlib
- joblib
- pathlib, PIL
- mahotas
- tqdm
- librosa
- tenpy

How to Run
----------
To run the code, convert the ipynb to executable script. Run the script using:

python main.py
