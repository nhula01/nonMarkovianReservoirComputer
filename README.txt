Non-Markovian Reservoir Computing Simulation
=============

Description
-----------
We model the evolution of a non-Markovian quantum system under a driving force from a task. In this project, we analyze the non-Markovian quantum reservoir on three different real world applications: stock market prediction, speech recognition, cancer prediction. On top of that, we show the competitive benchmark performance on Mackey Glass and Sine Square Task. Later on, we show some numerical indications of universality which adds a level of practicality to our mathematical proof.

Requirements
------------
Python packages needed:
- numpy
- pandas
- scipy
- scikit-sklearn
- matplotlib
- joblib
- pathlib, PIL
- mahotas
- tqdm
- librosa
- tenpy

How to Run
----------
To run the code, convert the ipynb to executable script. Run the script using:

python main.py
